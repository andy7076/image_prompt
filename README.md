# PROMPT/SIGNAL

一个面向 GPT-Image-2 灵感检索的响应式图片画廊。使用 React + Vite 构建，支持瀑布流、类型筛选、全文搜索、收藏、详情浏览和 Prompt 一键复制。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
